## About me

I'm a developer and educator who enjoys building practical software, understanding how things work, and occasionally reinventing something just to learn from it.

My background spans **web and mobile development, backend systems, and teaching computer science**. Lately, I've been spending more time with **Linux, self-hosting, automation, Rust, and embedded systems**.

I like clear architecture, thoughtful interfaces, open-source software, and tools that do one thing well. I tend to learn by building things I actually want to use.
